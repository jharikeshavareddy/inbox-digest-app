Privacy Policy

Last updated: 8 October 2026

Inbox Digest is a personal, self-hosted tool used only by its owner, Jakka Harikeshava Reddy, for the owner's own Google and Microsoft accounts.

What data it accesses

  • Email messages (read-only) via the Gmail API scope gmail.readonly and Microsoft Graph Mail.Read.
  • Calendar events (read-only) via calendar.readonly and Microsoft Graph Calendars.Read.

How it is used

The data is used only to display a summary page (action items, meetings, links, promotion counts) to the owner on the owner's own computer.

Storage and sharing

  • Data is processed on the owner's computer. Temporary run logs are kept for at most 72 hours and then deleted.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.
  • No email or calendar data is sent to any server other than Google's and Microsoft's own APIs.

Google API Services User Data Policy

Inbox Digest's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions or account.live.com/consent/Manage.
